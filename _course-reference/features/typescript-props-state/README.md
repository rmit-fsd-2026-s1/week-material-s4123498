# TypeScript Props And State Reference

Use this folder when you need a quick TypeScript component skeleton.

## Which File To Open

- `types-props-state-reference.tsx`: interfaces/types, props, `useState`, array rendering, and event handlers in one small example.

## Fast Memory

```text
type/interface -> describe data shape
Props          -> data passed into a component
useState       -> data owned by a component
map            -> render arrays
```
